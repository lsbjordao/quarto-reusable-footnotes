reusable-footnotes

Page-local reusable bibliographic footnotes for Quarto

Author

Lucas Sá Barreto Jordão

Published

September 22, 2026

Why this pattern matters

reusable-footnotes is designed for a citation pattern that is especially common in Law. Legal scholarship, briefs, opinions, memoranda, and books frequently place bibliographic references in page footnotes rather than relying only on a final reference list. The same practice is also familiar in History, Philosophy, Theology, Classics, literary studies, and other Humanities disciplines.

The important distinction is between the bibliographic source and its footnote occurrences. BibTeX should define the source once; Quarto should decide how that source is rendered wherever it is used.

For printable outputs, this has an important practical consequence. In PDF and DOCX, the reader can encounter the full source at the bottom of the same page as the proposition it supports. A reference cited again on another page can therefore appear again on that later page, while repeated uses on the same page can share one footnote.

The intended page-local behavior is:

page 1     A¹ ... A¹ ... B²
           ─────────────────
           ¹ Full reference A
           ² Full reference B

page 2     A³ ... A³ ... B⁴       # continuous numbering
           ─────────────────
           ³ Full reference A
           ⁴ Full reference B

or, when numbering restarts on every page:

page 1     A¹ ... A¹ ... B²
page 2     A¹ ... A¹ ... B²

In both cases, the source is repeated between pages, but not unnecessarily duplicated within the same page.

BibTeX and full bibliography entries

A normal Pandoc/Quarto citation remains completely unchanged:

A normal citation stays normal: [@silva2026].

For example: a normal citation stays normal (Silva 2026).

The development version of Fred Guth’s bibentry extension adds a second representation:

[@silva2026]{.bibentry}

That form prints the full bibliography entry using the bibliography layout of the active CSL style. It does not redefine what @silva2026 means.

Here is the full entry inline:

Silva, José Afonso da. 2026. Curso de Direito Constitucional Positivo. 47th ed. São Paulo: JusPodivm.

With:

bibliography: references.bib
csl: your-style.csl

ordinary citations use the CSL citation layout, while .bibentry extracts the corresponding bibliography-layout entry.

Legal-style footnotes

The useful composition remains native Pandoc syntax:

A legal proposition.^[See [@silva2026]{.bibentry}]

The result is a document in which each printed page carries the references needed to understand that page, while identical notes are not redundantly printed twice on the same page.

Configuration

The repository example uses page-local reuse and restarts footnote numbering on every page:

bibliography: references.bib

filters:
  - bibentry
  - reusable-footnotes

reusable-footnotes:
  enabled: true
  backlinks: true
  scope: page
  numbering: page
  docx-scope: pagebreak

format:
  html:
    toc: true
  pdf:
    toc: true
    pdf-engine: lualatex
  docx:
    toc: false
    reference-doc: _extensions/reusable-footnotes/reference-page.docx

The main options are:

  • scope: page: identical notes are reused only within the current page scope and may appear again later.
  • numbering: page: numbering restarts at 1 on every printed page.
  • numbering: continuous: numbering continues across pages while reuse remains page-local.
  • docx-scope: pagebreak: explicit boundaries define deterministic DOCX page scopes before Word performs final layout.
  • backlinks: true: HTML adds discreet return links for repeated calls to the same local footnote.

For continuous numbering, change only:

reusable-footnotes:
  scope: page
  numbering: continuous
  docx-scope: pagebreak

For DOCX page-local numbering, the supplied reference-page.docx configures Word’s native footnote counter to restart on each page. For continuous DOCX numbering, omit that reference document or use a custom continuous-numbering reference DOCX.

HTML websites and books

A standalone HTML document is one scrolling document, so there is no physical-page concept comparable to PDF or DOCX. The whole file is therefore one logical reusable-footnote scope.

A Quarto website or HTML book is different: each .qmd page or chapter is rendered as its own HTML page. The reusable-footnote scope starts fresh for every page, but numbering can either restart or continue globally.

Page-local numbering

Each rendered HTML page starts again at 1; repeated calls within the page reuse the local canonical footnote.

Because Quarto renders each HTML page independently, continuous project-wide numbering needs an explicit page order:

reusable-footnotes:
  scope: page
  numbering: continuous
  html-order:
    - index.qmd
    - doctrine.qmd
    - constitution.qmd

html-order is used only to calculate the numbering offset contributed by earlier pages. It does not merge their footnote scopes. A source cited on two pages can therefore appear in both pages’ footnote areas while receiving different numbers in a continuous sequence.

This gives four distinct, demonstrable HTML modes in the repository: website/local, website/global, book/local, and book/global.

Why BibTeX remains the source of truth

The author should not copy and paste formatted references into ^[...]. The .bib entry provides the stable bibliographic identity:

@book{silva2026,
  author    = {Silva, José Afonso da},
  title     = {Curso de direito constitucional positivo},
  edition   = {47},
  address   = {São Paulo},
  publisher = {JusPodivm},
  year      = {2026},
  note      = {Coedição Malheiros}
}

The same entry can then be represented in three different ways without duplicating data:

Normal citation: [@silva2026]

Full entry: [@silva2026]{.bibentry}

Full entry in a footnote: ^[See [@silva2026]{.bibentry}]

bibentry integration

This repository currently vendors an extended development version of Fred Guth’s bibentry extension under _extensions/bibentry/ for integration testing. The original project is MIT licensed and remains credited to Frederico Guth.

The proposed upstream changes add recursive AST support, including .bibentry inside native footnotes; true inline replacement; a single citeproc pass preserving numeric CSL ordering; and portable AST output for HTML, PDF/LaTeX, DOCX, and Typst.

bibentry and reusable-footnotes have separate responsibilities:

  • bibentry resolves a citation key and renders its full CSL bibliography form;
  • reusable-footnotes decides when an identical footnote occurrence should be reused locally or printed again on a later page.

Output formats

Format Page-local behavior
HTML document the whole HTML file is one logical page
HTML website/book each .qmd page owns its footnotes; numbering may restart or continue globally
PDF true physical-page reuse; identical notes print once per page and may reappear on later pages
DOCX exact reuse within explicit pagebreak-delimited pages; Word can restart numbering on every physical page through the supplied reference document

No Python runtime or post-render Python step is required.
